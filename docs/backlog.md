## 기능 추가

- [ ] 콘텐츠 수정 — 등록한 책/웹소설 정보(제목, 작가, 장르 등) 수정 기능
- [ ] 장르 관리 — 커스텀 장르 추가/삭제 기능 (설정 페이지)
- [ ] 커버 이미지 — 기본 이미지 선택 기능
- [ ] 커버 이미지 — 출간작 외부 API 연동 (카카오/네이버 책 API) 검색 후 자동 등록

- [ ] 장르 추천 — 보유 장르 기반 콘텐츠 추천
