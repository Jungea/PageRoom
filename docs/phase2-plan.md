# Phase 2 — 서점 운영 게임 시스템

## 핵심 루프

**책 읽기 → 독후감 작성 → 서점 진열 → 손님 매칭 → 평판/레벨업**

---

## 개발 순서

### 1단계 — 서점 진열

- 서재에서 `is_in_store` 토글 UI
- 서점 페이지(`/store`)에 진열된 책 목록 표시
- 읽은 작품만 진열 가능 (status: completed 권장)

---

### 2단계 — 손님 시스템

손님마다 취향, 요구 장르, 성격, 만족도 존재.

**손님 타입:**
| 타입 | 취향 |
|------|------|
| 대학생 | 철학/인문학 선호 |
| 직장인 | 가벼운 소설 |
| 매니아 | 특정 작가 컬렉션 |
| 웹소설 독자 | 최신 인기작 |

- 하루 단위 손님 방문 시뮬레이션
- 진열된 책과 취향 매칭 → 만족도 계산
- 손님 반응 대사: **템플릿 방식** (추후 Claude API로 교체 예정)

---

### 3단계 — 평판/레벨업

- 만족도 누적 → `store_reputation` 증가
- `store_level` 레벨업 조건 및 혜택 정의
- 장르 편향 경고: 특정 장르 비중 과다 시 알림
- 희귀작(숨겨진 명작) 보유 시 특수 손님 등장 및 평판 보너스

---

### 4단계 — 독후감 × 서점 연동

독후감 품질이 서점 운영에 영향:

| 독후감 수준 | 효과 |
|------------|------|
| 좋은 독후감 | 단골 증가, 추천 정확도 향상, 전문 분야 강화 |
| 분석 키워드 풍부 | 손님 매칭 정확도 향상 |

- `ai_keywords`, `ai_emotion`, `ai_depth` 컬럼 이미 DB에 존재
- 현재는 미입력 상태 → 4단계에서 활용

---

## DB 현황 (이미 존재하는 컬럼)

| 테이블 | 컬럼 | 용도 |
|--------|------|------|
| `reading_records` | `is_in_store` | 서점 진열 여부 |
| `user_profiles` | `store_level` | 서점 레벨 |
| `user_profiles` | `store_reputation` | 서점 평판 점수 |
| `reviews` | `ai_keywords` | AI 분석 키워드 |
| `reviews` | `ai_emotion` | AI 감정 분석 |
| `reviews` | `ai_depth` | AI 깊이 분석 |

---
