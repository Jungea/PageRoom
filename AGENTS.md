# Workflow Rules

## Code Changes
Before making any edits, show what needs to change and get confirmation first.
Never modify code directly without showing the plan and receiving confirmation.

## Commits
Group related changes into a single commit. Do not commit after every small edit.
During testing or debugging sessions, hold off on committing until all related fixes are done.
When the user says "커밋해줘", group all pending changes by common theme and commit them together.
Write commit messages in Korean.

## Pushes
Do not push. The user handles pushing manually.
